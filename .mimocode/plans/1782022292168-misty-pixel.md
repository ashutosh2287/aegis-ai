# Premium Gym-Themed Auth Pages Redesign

## Goal
Restyle Login and Register pages with a dark + gold premium gym aesthetic. Split-screen layout (hero left, form right). Auth pages only — internal app pages stay unchanged.

## Design Direction
- **Palette**: Black/charcoal (#0a0a0a, #1a1a1a) + gold accents (#d4a843, #c9a227)
- **Layout**: Split screen — left hero panel with branding, right form panel
- **Typography**: Bold headings, tight tracking, muted body text
- **Brand**: "AEGIS AI" — shield + lightning bolt logo (inline SVG, gold on dark)
- **Visual**: CSS-only geometric grid pattern on hero (no image assets needed)

## Implementation Steps

### Step 1: Theme Tokens (`src/index.css`)
Add before `@tailwind` directives:
```css
@theme {
  --color-aegis-black: #0a0a0a;
  --color-aegis-charcoal: #1a1a1a;
  --color-aegis-dark: #111111;
  --color-aegis-gold: #d4a843;
  --color-aegis-gold-dark: #c9a227;
  --color-aegis-gold-light: #e8c96a;
  --color-aegis-border: #2a2a2a;
  --color-aegis-muted: #888888;
}
```

### Step 2: AuthLogo Component
Inline SVG: shield outline + lightning bolt path, gold color. "AEGIS" white + "AI" gold text.

### Step 3: AuthInput Component
Dark input (`bg-aegis-dark`, `ring-aegis-border`, `focus:ring-aegis-gold`). Props: `label`, `error`, spread remaining `inputHTMLAttributes`.

### Step 4: AuthHero Component
- Gradient background: `bg-gradient-to-br from-aegis-charcoal via-aegis-black to-aegis-black`
- Radial gold glow: `bg-[radial-gradient(ellipse_at_center,_rgba(212,168,67,0.08)_0%,_transparent_70%)]`
- CSS grid pattern: thin gold lines at 3% opacity
- Content: AuthLogo (large), tagline "Train Smarter. Grow Faster.", subtitle, gold divider, stats strip (10K+ Athletes / 500+ Exercises / AI Powered)

### Step 5: AuthLayout Component
```
<div className="min-h-screen flex bg-aegis-black">
  {/* Left: hero — hidden mobile, flex-1 on lg+ */}
  <div className="hidden lg:flex lg:flex-1 ...">
    <AuthHero />
  </div>
  {/* Right: form — full-width mobile, flex-1 on lg+ */}
  <div className="flex-1 flex items-center justify-center p-6 sm:p-12">
    <div className="w-full max-w-md">
      <div className="lg:hidden mb-8 text-center"><AuthLogo /></div>
      {children}
    </div>
  </div>
</div>
```

### Step 6: PasswordStrengthBar Dark Theme
- `bg-gray-200` → `bg-aegis-border`
- Text color → `text-gray-400`

### Step 7: LoginPage Rewrite
- Wrap in `<AuthLayout>`
- Heading: "Sign in to your account" + subtitle
- Inputs via `<AuthInput>` with gold focus rings
- Password toggle icon: `text-aegis-muted`
- Remember me checkbox: `text-aegis-gold focus:ring-aegis-gold border-aegis-border bg-aegis-dark`
- Forgot password link: `text-aegis-gold hover:text-aegis-gold-light`
- Submit button: `bg-aegis-gold text-aegis-black hover:bg-aegis-gold-light` with subtle gold glow shadow
- Sign up link: `text-aegis-gold hover:text-aegis-gold-light`
- Framer-motion fade-in-up on form container

### Step 8: RegisterPage Rewrite
Same pattern as login +:
- First/Last name grid (2 cols)
- PasswordStrengthBar between confirm password and submit
- Newsletter checkbox (gold themed)
- "Create account" button text
- "Already have an account? Sign in" link
